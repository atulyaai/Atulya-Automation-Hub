# Atulya Automation Hub

One-click business automation platform for India. Integrates Office, GST, SAP, HR, ERP, and utilities into a single command center.

## Features

- Centralized dashboard for all Atulya tools
- One-click automation workflows
- Cross-tool integrations
- CLI and GUI interfaces
- Extensible plugin system

## Quick Start

```bash
# Install
pip install atulya-automation-hub

# Launch hub
atulya dashboard

# Run a workflow
atulya run workflow-name.yaml
```

## Included Tools

| Tool | Purpose |
|------|---------|
| Atulya Office | Excel, Word, Outlook, PPT automation |
| Atulya GST Suite | GST reconciliation & filing |
| Atulya SAP Automations | SAP GUI workflow automation |
| Atulya HR Suite | HR & payroll management |
| Atulya Accounting ERP | Accounting & inventory |
| Atulya Data Scruber | Data cleaning & transformation |
| Atulya All File Converter | Universal file conversion |
| Atulya Launch | Hosting control panel |
